REQUIREMENT

1. Install python
2. Install modul di cmd klik kanan pada folder > open in terminal > lalu ketik

python -m pip install -r modulepython.txt

untuk versi code ini, bisa per instansi, per provinsi, atau per wilker kanreg, instansi ini bisa pemkot/pemprov/pemkab/instansi pusat, provinsi hanya untuk wilayah per prov, wilker untuk kanreg

untuk run silahkan klik kanan di folder ini > open in terminal > lalu ketik ini

untuk per instansi
python main.py --instansi (nama instansi yang ingin digenerate) 

contoh :

python main.py --instansi "badan kepegawaian negara"

untuk per provinsi
python main.py --provinsi (nama wilayah)

contoh : 

python main.py --wilker "jawa barat"

untuk per kanreg
python main.py --kanreg (id kanreg 2 digit)

contoh :

python main.py --kanreg 05

hasil ada di folder output
